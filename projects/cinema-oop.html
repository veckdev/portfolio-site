Cinema Booking 1

Personal project · Java

A personal Java booking application that models seat availability, age-based ticket prices, cancellations, and purchase history in a command-line interface.

  • Java
  • OOP
  • File persistence
  • State management
  • Validation

The problem

Represent a cinema booking flow with clear rules for seat reservations, pricing, and cancellation, including preventing the same seat from being booked twice.

The implementation

The app layer handles CLI flow while the model layer holds domain logic and state. Tickets receive IDs, purchase history is stored in a file, and validation handles invalid input.

Skills in practice

The project applies object-oriented modelling to a stateful problem, connecting booking rules with input handling and file-based persistence.
