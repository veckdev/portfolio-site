Library System 1

Personal project · Java fundamentals

A personal Java project exploring object-oriented design through a small library system, with book search, borrowing validation, and separate app, model, and service layers.

  • Java
  • Encapsulation
  • Collections
  • Layered design

The problem

Model a library’s books and borrowing operations in a small application with explicit responsibilities.

The implementation

The Book model represents library items, the Library service manages the collection and borrowing rules, and the application exposes a Scanner-based menu. Core Java collections store the books.

Skills in practice

The project provides focused practice in encapsulation, collections, and keeping business rules separate from command-line interaction.
