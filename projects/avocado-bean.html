Avocado Bean

Team project

A team-built website for a fictional plant-based ingredient delivery service, with recipe browsing and interactive order forms.

  • JavaScript
  • Responsive design
  • Form validation
  • DOM manipulation
  • Teamwork

The problem

Present recipes and let visitors assemble an order for a fictional delivery service.

The implementation

The project includes search and category filters, recipe modals, an order summary, and client-side form validation. I participated as a member of the team.

Skills in practice

Bring multiple pages and interactive features into a shared web project. The implementation described here belongs to the team as a whole.
