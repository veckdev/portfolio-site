André Esperidião — Portfolio 55

Personal project · Web development

A personal web project presenting photographer André Esperidião’s work through an editorial gallery, individual project pages, and a consistent multi-page layout.

  • HTML & CSS
  • JavaScript
  • Content modelling
  • Multi-page navigation

The problem

Give a photographer’s work a clear browsing structure, moving from an overview of the portfolio to the images and context of an individual project.

The implementation

Project information is defined in JavaScript and used by the gallery and detail page. Shared styles connect the home, work, about, and contact pages, and the static website is hosted on GitHub Pages.

Skills in practice

This project explores content modelling and reusable page structure, keeping project data separate from the presentation of the gallery and individual stories.
