Smart Waste Collection Network 35

Academic project · Distributed systems

A university project simulating a smart waste collection network. Three Java services coordinate bins, collection routes, and recycling centres through gRPC.

  • Java
  • gRPC
  • Protocol Buffers
  • Service discovery
  • Distributed systems

The problem

Model how independently running services can coordinate municipal waste collection, from monitoring bin levels to assigning collections and receiving deliveries at recycling centres.

The implementation

The application separates Smart Bin, Collection, and Recycling Centre services. Protocol Buffers define their contracts, gRPC supports unary and streaming communication, and jmDNS handles service discovery. Requests carry metadata and deadlines; a Swing client shows which services are available.

Skills in practice

This project put distributed systems concepts into practice: defining service contracts, choosing communication patterns, coordinating services, and representing partial availability in a client.
